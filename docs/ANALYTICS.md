# Аналитика цен — методика расчётов

Ozon Price Tracker фиксирует цены **в моменты успешных проверок**. Он не располагает непрерывной информацией обо всех промежуточных изменениях на маркетплейсе.

## Что показывается

- **Стартовая цена** — первая успешная запись для соответствующего вида цены («По карте Ozon» или «С другими банками»).
- **Текущая/последняя** — последнее сохранённое значение с датой проверки. Если запрос не удался, последняя цена не считается актуальной.
- **Изменение** — разница между последней и первой ценой (в рублях и процентах).
- **Минимум/максимум** — экстремумы среди замеров с датами, а не гарантированные биржевые/рыночные экстремумы между замерами.
- **Средняя по замерам** — арифметическое среднее записанных значений.
- **Ориентировочная средняя с учётом времени** — средневзвешенное значение при допущении, что цена оставалась неизменной между двумя последовательными проверками. Это оценка, а не гарантированная фактическая цена каждую минуту.
- **Изменение за 24 часа и 7 дней** — сравнение с имеющимися историческими замерами; если данных недостаточно, статистика это сообщает.

## Два типа банковских цен

Серии отслеживаются отдельно. Если сервер выдаёт только одну цену без явного типа банковской скидки, приложение не приписывает её произвольно другой категории. Для автоматических уведомлений требуется подтверждённая цена выбранного типа.

## Миграция истории

Старые замеры могут содержать только цену выбранной категории. Историческая серия для второго типа не реконструируется из текущей цены; она начинает накапливаться с момента появления достоверных замеров.

## Связанные файлы

- `app/analytics.py` — расчёты.
- `app/database.py` — сохранение замеров.
- `app/static/app.js` — отображение графиков и показателей.
- `app/telegram_bot.py` — аналитические сообщения.
